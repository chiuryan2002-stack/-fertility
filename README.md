# 阿美語、華語、英語的斷詞比較：BPE / WordPiece / Unigram LM

互動網頁：比較三種子詞切分演算法在阿美語、華語、英語上的 fertility、切點對齊，以及被切壞的詞綴與構式。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 單檔互動網頁（資料已內嵌），GitHub Pages 的首頁 |
| `analysis.py` | 讀取語料、從頭實作並訓練三種演算法、輸出統計 |
| `results.json` | `analysis.py` 的完整輸出（`index.html` 內嵌的就是這份） |
| `summary.csv` | 各設定的 fertility 與對齊指標總表 |

## 重新產生結果

```
python3 analysis.py <語料資料夾> <輸出資料夾>
```

語料檔名需為 `前5篇_amis.rtf`、`前5篇_chinese.rtf`、`前5篇_english.rtf`。只用 Python 標準庫，不需另外安裝套件。

## 語料來源與限制

- 台大台灣南島語語料庫 <https://corpus.linguistics.ntu.edu.tw/#/>，阿美語（長光）前五篇，口語語料，體裁為故事。
- 阿美語語料僅限長光地區；阿美語有地區差異（南勢、秀姑巒、海岸、馬蘭、恆春），其他地區的詞彙分配仍需進一步探究。
- 英語詞素依英語構詞規則（屈折詞尾與縮寫依拼寫規則、派生詞綴須詞幹在語料中出現）計算，無人工標註，英語的 P／R 為規則估計。
- 三種演算法皆為本專案在小型語料上從頭實作，結果說明機制，不等同於商用模型的行為。
