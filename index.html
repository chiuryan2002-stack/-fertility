同一句話，三種切法

最上一列是語言學切分（阿美語與英語以詞素、華語以人工斷詞之標準），其下是三個演算法的切法。顏色標示每個 token 與語言學單位的關係。

Fertility：每個詞被切成幾個 token

fertility ＝ 總 token 數 ／ 總詞數。詞的定義：阿美語由原人工標註之連字號還原成正字法的詞，華語及英語用人工斷詞之標準。下表為目前的額外子詞數與訓練語料設定。

論證：兩種單位各自在解什麼問題

以下數字取自基準設定（BPE、三語合訓、額外 150 個子詞），其他設定沿用同一個傾向，可用上方控制項自行驗證。

一、fertility 量的是基礎指標，接近 1 不代表切出了詞

在基準設定下，每詞 token 數分別為：阿美語 2.18、英語 2.32、華語 1.14。阿美語和英語幾乎一樣高，因為這批語料中兩者的平均詞長只差一點（每詞約 4.5 對 4.0 個字元），形態複雜度沒有直接反映在 fertility 上；華語則接近 1，是因為華語詞彙很短（平均 1.2 字），每字元 0.94 個 token，也就是大致一字一 token，並不是模型學會了詞。因此，當預算（預設）變大，華語 fertility 反而降到 1 以下（額外 1000 時為 0.84），因為 token 開始會將相鄰的詞吃掉，所以 fertility 只能當基礎指標，判斷詞彙單位是否能對得上仍要看實際語言的詞彙邊界。

二、詞綴容易被模型發現並選取，詞幹則容易被模型打碎：詞彙的容量會跟著使用頻率提高，而不是隨著功能改變

阿美語的 704 個詞綴出現中，566 次（80%）剛好是一個 token，例如 ma-、mi-、-tu、-ay。但同一個模型對詞幹的選取模式卻不一樣：2,492 個詞幹出現中，1,193 次（48%）被切成兩片以上。全部 5,464 個阿美語 token 裡，只有 32% 剛好是一個詞素，66% 是詞素內部的碎片。實例：mi-kilim → mi|kil|i|m、falucu’ → f|alu|cu|’、finawlan → f|in|aw|l|an。

造成此現象的原因是源於機制上的：詞綴短而重複多，因此能快速帶進詞彙，而詞幹則偏長、種類繁多、亦不常見，所以模型只能將其拆成常見的字母組合。語言學上詞幹會帶出詞彙意義、詞綴則可見其語法，而詞彙容量的分配正好相反。

三、正字法的字母也不是單位：喉塞音 ’ 與 ng

阿美語正字法把 ’ 當成字母（喉塞音）。基準設定下 254 個 ’ 有 94 個（37%）自成一個 token，與前面的母音分開；WordPiece 額外 1000 時這個比例升到 89%（227 個）。ng 是雙字母的單一音位，BPE 只有 18 次（9%）切在 n 與 g 之間，Unigram（額外 150）與 WordPiece（額外 1000）都是 0 次，所以雙字母會被模型學成同一塊詞素，喉塞音卻會被當成標點般的獨立符號。

四、華語的語言單位分歧方向相反：模型合併，斷詞切開

BPE 把 我們（33 次）、這樣（28 次）、沒有（17 次）合成一個 token，而斷詞把它們切成 我 們、這 樣、沒 有。反方向的切分也存在：什麼（16 次）、所以（13 次）、時候（11 次）、過去（11 次）、小孩（10 次）在這個預設下都被拆成單字。WordPiece 額外 1000 時，27% 的華語 token 跨越斷詞邊界，詞內邊界的 recall 掉到 0.61。詞彙單位是被壓縮的，會跟著共現頻率改變，與斷詞規範的切點只在「頻繁且短」的地方重合。

五、共享詞彙有代價，預設分配是模型演算法的副作用

同樣額外 150 個子詞，三語合訓比各語單訓的 fertility 高：阿美語 2.18 對 1.88，英語 2.32 對 1.99（BPE）。WordPiece 更明顯：合訓時額外 50 到 400 個子詞，阿美語與英語的 fertility 幾乎不變（4.46 與 3.99，等於平均詞長，即字母級）：前 400 次合併中有 397 次含中文字，因為概似分數偏愛低頻的配對，而罕見的華語字組正是這種配對。詞彙裡各語言分到多少位置，取決於演算法的評分方式，並不是語言學上的決定。

小結

三個分歧點：（1）詞彙單位按頻率分配，語言學單位按功能分工（詞綴對詞幹）；（2）詞彙單位不尊重原本內部的音位單位（如：喉塞音）；（3）詞彙單位的邊界與斷詞規範的方向不固定，會把詞合併也會把詞拆開。三種演算法在這些特點上的差異，主要來自於模型訓練準則（頻率、概似、機率模型）與編碼方式（合併順序、最長匹配、Viterbi），對齊語言學單位並不在模型的目標函數中。

語料來源與研究限制

語料來源：台大台灣南島語語料庫，阿美語（長光）前五篇語料；語料類型為口語語料，體裁為故事。

研究限制：本次研究之阿美語語料僅以長光地區為研究範圍，但阿美語具地區性差異（如：南勢阿美語 Amisay a Pangcah、秀姑巒阿美語 Siwkolan ’Amis、海岸阿美語 Pasawalian Pangcah、馬蘭阿美語 Farangaw Amis、恆春阿美語 Palidaw ’Amis），因此不同地區之阿美語在語言學上的詞彙分配常態仍需進一步探究。

方法與限制

語料：三種語言各取前 5 篇；阿美語 959 行、華語 499 行、英語 452 行，三者不是逐行對齊。阿美語的詞由連字號標註還原（ma- sa- ma’an -tu → masama’antu，詞素邊界取自連字號），若你的正字法把附著成分獨立書寫，詞數與 fertility 會不同。演算法：BPE、WordPiece、Unigram LM 由 analysis.py 從頭實作並在這批語料上訓練（環境無法下載預訓練詞彙）。WordPiece 用概似分數合併且配對至少出現 2 次，編碼為最長匹配；Unigram 以 EM 估計並以期望次數剪枝（簡化版，非 SentencePiece 的損失剪枝）。英語與阿美語以空白預切，華語以整行不含空白訓練，token 可跨越斷詞邊界。英語詞素依英語構詞規則計算：屈折詞尾（-s／-es、-ed、-ing）與縮寫（n’t、’s、’re、’ll 等）依拼寫規則切分（去 e、sibilant 後加 -es、子音重複，如 put|ting），並排除 this、was、morning 等詞彙化的少數例外；派生詞綴（-er、-ly、-ness、-ful、-less、-able、un-、re-、dis-）須詞幹也在語料中出現才切分；專有名詞不套用屈折規則。英語沒有人工詞素標註，因此英語的 P／R 是規則估計，可能與人工標註有出入。規模：每語約 2–3 千詞，只能說明機制；要換成真實模型，把 analysis.py 裡的編碼函式換成預訓練 tokenizer 的切分即可。
